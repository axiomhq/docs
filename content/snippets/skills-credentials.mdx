## Install Axiom Skills

Install Axiom Skills as a plugin to get all skills together with the hosted [Axiom MCP Server](/console/intelligence/mcp-server) (using OAuth), or use the standalone skills installer.

### Install as a plugin

- **Claude Code:**

    ```bash
    claude plugin marketplace add axiomhq/skills
    claude plugin install axiom@axiom
    ```

    Restart Claude Code, and then run `/mcp` to authorize Axiom in your browser.

- **Codex:**

    ```bash
    codex plugin marketplace add axiomhq/skills
    codex plugin add axiom@axiom
    ```

    Authorize Axiom in your browser when prompted. If you already added Axiom MCP manually, keep one connection to avoid duplicate tools.

- **Cursor:**

    On Teams or Enterprise plans, an admin must enable **Allow Local Plugin Imports**, or import `axiomhq/skills` through **Plugins & MCPs > Add Marketplace > Import from Repo** in the Cursor dashboard. To install locally, clone into Cursor’s local plugin directory:

    ```bash
    git clone https://github.com/axiomhq/skills.git ~/.cursor/plugins/local/axiom
    ```

    Reload Cursor and authorize Axiom when prompted.

- **Amp:**

    Clone into Amp’s system plugin directory, and then add Axiom MCP Server separately (Amp plugins can’t declare MCP servers):

    ```bash
    git clone https://github.com/axiomhq/skills.git ~/.config/amp/plugins/axiom
    amp mcp add axiom https://mcp.axiom.co/mcp
    ```

    Restart Amp and authorize Axiom when prompted.

- **Gemini CLI:**

    ```bash
    gemini extensions install https://github.com/axiomhq/skills
    ```

    Restart Gemini CLI, and then run `/mcp auth axiom` to authorize Axiom.

### Install standalone skills

To install all skills without configuring the hosted MCP Server:

```bash
npx skills add axiomhq/skills
```

### Configure Axiom credentials

Plugin installations connect the hosted Axiom MCP Server with OAuth, but MCP OAuth doesn’t configure credentials for script-based skills.

For dashboard, alerting, and metrics scripts, create a configuration file at `~/.axiom.toml`. For the SRE skill, configure `~/.config/axiom-sre/config.toml` as described in [Set up the SRE skill](/console/intelligence/skills/sre#set-up-the-sre-skill). Cost-control workflows use both SRE queries and dashboard scripts, so configure both files.

```toml ~/.axiom.toml
[deployments.dev]
url = "https://api.axiom.co"
token = "API_TOKEN"
org_id = "ORGANIZATION_ID"
edge_url = "AXIOM_DOMAIN"
```
