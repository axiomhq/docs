Axiom offers the following approaches to capture generative AI telemetry:

| Instrumentation approach    | Language support | Characteristics                                                   |
|:-----------------------------|:------------------|:----------------------------------------------------------------|
| [Vercel AI SDK](/use-cases/llm-observability/axiom-ai-sdk-instrumentation)                | TypeScript       | Quick setup.<br/>Minimal code changes.                            |
| [Manual](/use-cases/llm-observability/manual-instrumentation)                      | Any              | More involved setup.<br/>Full control over instrumentation.       |

**Instrumentation with Vercel AI SDK** is the right choice for you if you have a TypeScript app built with Vercel AI SDK. Vercel AI SDK 7 emits traces with the correct semantic conventions natively, so you only export them to Axiom. For Vercel AI SDK 4, 5, and 6, Axiom AI SDK captures the traces.

**Manual instrumentation** is the right choice for you if you want to use your own tooling or if you use a language other than TypeScript. You need to instrument your app manually to emit traces compatible with Axiom’s LLM observability features.

Both approaches emit OpenTelemetry GenAI attributes. This means that all the telemetry analysis features work the same way.
