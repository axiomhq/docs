## Create a dashboard element

1. In the sidebar, click **Dashboards** and open the dashboard to which you want to add the {props.elementName}.
1. Click **Edit dashboard**.
1. Click <Icon icon="plus" iconType="regular"/> **Add element** in the top right corner.
1. Select **{props.elementButtonLabel}** from the **Add element** menu (under **Chart > Chart aggregation** or **Data**).
1. Choose one of the following:
    - Click **Builder** to create your chart using a visual query builder. For more information, see [Create chart using visual query builder](/dashboard-elements/create#create-chart-using-visual-query-builder).
    - Click **Editor** to create your chart using the Axiom Processing Language (APL). Create a chart in the same way you create a chart in the [Editor](/query-data/query-editor).
1. Optional: [Configure the dashboard element](/dashboard-elements/configure).
1. Click **Save**.

The new element appears in your dashboard. In the page header, click **Save dashboard** to save your changes to the dashboard.
