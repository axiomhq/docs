---
title: Vacuum dataset
openapi: "v2 post /datasets/{dataset_id}/vacuum"
---

<Note>
When the endpoint returns `200`, the vacuum job is queued and runs asynchronously. The vacuum itself can take several hours to complete.

Only one dataset job can run at a time on a dataset. There is no hourly cooldown and this endpoint doesn't return `429` for rate limits. If another job (such as a trim, vacuum, field deletion, or dataset deletion) is already active on the dataset, Axiom returns `409 Conflict` with a JSON body containing `message` and `blockingJobs` (a map of active job IDs to job types). Wait for the blocking job to finish before retrying.
</Note>
