---
title: Trim dataset
openapi: "v2 post /datasets/{dataset_id}/trim"
---

<Note>
When the endpoint returns `200`, the trim job is queued and runs asynchronously. The deletion itself can take several hours to complete.

Only one dataset job can run at a time on an events or logs dataset (and on a metrics dataset, a trim can't run while another trim is active). If a conflicting job is already active on the dataset, Axiom returns `409 Conflict` with a JSON body containing `message` and `blockingJobs` (a map of active job IDs to job types). Wait for the blocking job to finish before retrying.
</Note>
