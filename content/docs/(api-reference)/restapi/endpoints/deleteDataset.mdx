---
title: Delete dataset
openapi: "v2 delete /datasets/{dataset_id}"
---

<Note>
If another dataset job (such as a trim, vacuum, field deletion, or dataset deletion) is already active on the dataset, Axiom returns `409 Conflict` with a JSON body containing `message` and `blockingJobs` (a map of active job IDs to job types). Wait for the blocking job to finish before retrying.
</Note>
