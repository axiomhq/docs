---
title: Create user
openapi: "v2 post /users"
---

<Note>
Using this endpoint, you can invite a user to your organization. Axiom sends an invite email to the email address you specify. If the email address already belongs to an Axiom account, Axiom keeps the account’s existing name.

Authorize the request with one of the following:
- An [API token](/reference/tokens#api-tokens) with the **Create** permission for **Users** in the org level permissions. API tokens can’t assign the `owner` role.
- A [personal access token (PAT)](/reference/tokens#personal-access-tokens-pat) of a user with permission to create users. Only an owner can assign the `owner` role.
</Note>
