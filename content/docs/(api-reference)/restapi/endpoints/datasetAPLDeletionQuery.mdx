---
title: Delete events by query
openapi: "v2 post /datasets/_apl/delete"
---

<Warning>
This endpoint deletes every storage block that contains at least one matching event, so it can delete events that don't match your query. Always start with a dry run (`commit` set to `false`) and compare `rowsMatched` with `rowsDeleted`. For more information, see [Delete blocks](/restapi/delete-blocks).
</Warning>
