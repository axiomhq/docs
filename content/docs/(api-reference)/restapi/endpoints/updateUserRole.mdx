---
title: Update user role
openapi: "v2 put /users/{id}/role"
---

<Note>
Using this endpoint, you can change the role of a user in your organization. To get the ID of the user, use the [List all users](/restapi/endpoints/getUsers) endpoint.

Authorize the request with one of the following:
- An [API token](/reference/tokens#api-tokens) with the **Update** permission for **Users** in the org level permissions. API tokens can’t assign the `owner` role or change the role of an existing owner.
- A [personal access token (PAT)](/reference/tokens#personal-access-tokens-pat) of a user with permission to update users. You can’t change your own role. Only an owner can assign the `owner` role or change the role of an existing owner.
</Note>
