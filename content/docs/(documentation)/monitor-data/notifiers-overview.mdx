A monitor is a background task that periodically runs a query that you define. For example, it counts the number of error messages in your logs over the previous 5 minutes. A notifier defines how Axiom notifies you about the monitor output. For example, Axiom can send you an email.

By adding a notifier to a monitor, you receive a notification with the following message:
- When a match monitor matches an event, the message contains the fields returned by the query for that event.
- When a threshold monitor changes state, the message includes a relevant value from the query results. If you enable **Notify by group**, the notification message also contains the relevant group value.
- When an anomaly monitor changes state, the message explains why the monitor triggered or resolved.
- When a new values monitor triggers, the message contains the new value.

To change the title and body of a monitor’s Slack, Microsoft Teams, Discord, and email notifications, use a [message template](/monitor-data/message-templates).

For threshold and anomaly monitors, [notification settings](/monitor-data/configure-monitors#notification-settings) control repeated alerts and resolve notifications.

## Notification limits

Axiom limits alert notifications to 500 runs per monitor per day. Each run counts once, even if it sends several notifications. If four runs send alerts with less than 30 seconds between them, Axiom waits another 30 seconds before sending more alert notifications.

When either notification limit is reached, Axiom skips alert notifications and reports the number of skipped alerts in a later notification. These limits don’t apply to resolve notifications.
