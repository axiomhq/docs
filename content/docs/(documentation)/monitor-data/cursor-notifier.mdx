Use a Cursor notifier to send monitor alerts to a Cursor automation.

To create a Cursor notifier, follow these steps:

1. Create and save a Cursor automation with a webhook trigger. For more information, see the [Cursor documentation](https://cursor.com/docs/cloud-agent/automations#webhook-triggers).
1. In Axiom, click **Notifiers** in the sidebar.
1. Click **New notifier**.
1. Name your notifier.
1. Click **Cursor**.
1. In **Automation webhook URL**, enter the webhook URL of the automation.
1. In **Cursor bearer token**, enter the API key of the webhook trigger.
1. Click **Create**.
