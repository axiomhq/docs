Use an Opsgenie notifier to use all the incident management features of Opsgenie with Axiom.

To create an Opsgenie notifier, follow these steps:

1. In Opsgenie, create an API integration. For more information, see the [Opsgenie documentation](https://support.atlassian.com/opsgenie/docs/create-a-default-api-integration/).
1. Click the **Monitors** tab, and then click **Manage notifiers** on the right.
1. Click **New notifier** on the top right.
1. Name your notifier.
1. Click **Opsgenie**.
1. Enter the API key you have previously generated.
1. Select the region of your Opsgenie instance.
1. Click **Create**.

## Threshold levels

When a threshold monitor has [threshold levels](/monitor-data/threshold-monitors#threshold-levels), the priority of the Opsgenie alert follows the severity of the level:

| Level severity | Opsgenie priority |
| --- | --- |
| `critical` | `P1` |
| `error` | `P2` |
| `warning` | `P3` |
| `info` | `P5` |

When the alert escalates or de-escalates, Axiom updates the priority of the open Opsgenie alert to match the new level. Alerts from monitors without levels use the default priority of your Opsgenie integration.

Jira Service Management notifiers map severities to priorities in the same way.
