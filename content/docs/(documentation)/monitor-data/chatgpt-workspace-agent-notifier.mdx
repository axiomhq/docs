Use a ChatGPT Workspace Agent notifier to send monitor alerts to a published workspace agent.

To create a ChatGPT Workspace Agent notifier, follow these steps:

1. Publish your workspace agent with an API channel. For more information, see the [OpenAI documentation](https://developers.openai.com/workspace-agents/trigger-runs).
1. Create a Workspace Agent access token. For more information, see the [authentication documentation](https://developers.openai.com/workspace-agents/authentication).
1. In Axiom, click **Notifiers** in the sidebar.
1. Click **New notifier**.
1. Name your notifier.
1. Click **ChatGPT Workspace Agent**.
1. In **API channel trigger ID**, enter the trigger ID of the published API channel.
1. In **Workspace agent token**, enter your Workspace Agent access token.
1. Click **Create**.
