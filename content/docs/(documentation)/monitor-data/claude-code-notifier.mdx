Use a Claude Code notifier to send monitor alerts to a Claude Code routine.

To create a Claude Code notifier, follow these steps:

1. Create a Claude Code routine with an API trigger. For more information, see the [Claude Code documentation](https://code.claude.com/docs/en/routines#add-an-api-trigger).
1. In the routine prompt, tell Claude Code to investigate the alert in the `routine-fire-payload` block.
1. In Axiom, click **Notifiers** in the sidebar.
1. Click **New notifier**.
1. Name your notifier.
1. Click **Claude Code**.
1. In **Routine ID**, enter the ID between `/routines/` and `/fire` in the routine’s fire URL.
1. In **Claude Code bearer token**, enter the token of the API trigger.
1. Click **Create**.
