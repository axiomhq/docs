Use aggregations to count events, compare groups, and summarize numeric fields. The examples on this page show each query together with its charts and result summary.

The examples use `sample-http-logs`. Group by `bin_auto(_time)` to compare results over time. Add another grouping field, such as `method`, to compare series within each time interval. A query with multiple aggregations produces multiple results; inspect each chart and its corresponding summary column.

<Info>
These examples use APL queries.

To visualize metrics data, see [MPL language features](/mpl/introduction).
</Info>

## `count`

The `count` visualization counts all matching events and produces a time series chart.

#### Arguments

This visualization doesn’t take an argument.

#### Group-by behaviour

The visualization produces a separate result for each group plotted on a time series chart.

```kusto
['sample-http-logs']
| summarize count()
    by bin_auto(_time), method
```

## `distinct`

Use [`dcount`](/apl/aggregation-function/dcount) to estimate the number of distinct values in a field. Group the result by time to plot how that count changes. This example compares the number of distinct cities for each HTTP method.

#### Arguments

`field: any` is the field to aggregate.

#### Group-by behaviour

The visualization produces a separate result for each group plotted on a time series chart.

```kusto
['sample-http-logs']
| summarize dcount(['geo.city'])
    by bin_auto(_time), method
```

## `avg`

The `avg` visualization averages the values of the field inside the dataset and produces a time series chart.

#### Arguments

`field: number` is the number field to average.

#### Group-by behaviour

The visualization produces a separate result for each group plotted on a time series chart.

```kusto
['sample-http-logs']
| summarize
    avg(req_duration_ms),
    avg(resp_body_size_bytes),
    avg(resp_header_size_bytes)
    by bin_auto(_time),
    method
```

## `percentiles`

Percentile aggregations estimate the value below which a given percentage of observations falls. Use `percentile(field, 95)` for the 95th percentile, or `percentiles(field, 95, 99)` for several percentiles.

#### Arguments

- `field: number` is the number field where Axiom calculates the percentiles.
- `percentiles: number [, ...]` is a list of percentiles, each a number between 0 and 100. For example, `percentiles(request_size, 95, 99, 99.9)`.

#### Group-by behaviour

Group by time to compare percentiles across intervals. This example shows a separate chart for the 95th percentile of request duration, response body size, and response header size.

```kusto
['sample-http-logs']
| summarize
    percentile(req_duration_ms, 95),
    percentile(resp_body_size_bytes, 95),
    percentile(resp_header_size_bytes, 95)
    by bin_auto(_time)
```

## `histogram`

The `histogram` visualization buckets the field into a distribution of N buckets, returning a time series heatmap chart.

#### Arguments

- `field: number` is the number field where Axiom calculates the distribution.
- `nBuckets` is the number of buckets to return. For example, `histogram(request_size, 15)`.

#### Group-by behaviour

The visualization produces a separate result for each group plotted on a time series histogram. Hovering over a group in the totals table shows only the results for that group in the histogram.

```kusto
['sample-http-logs']
| summarize
    histogram(req_duration_ms, 10),
    histogram(resp_body_size_bytes, 10),
    histogram(resp_header_size_bytes, 10)
    by bin_auto(_time)
```

## `topk`

The `topk` aggregation estimates the most frequent values of a field in a dataset.

#### Arguments

- `field` is the field whose most frequent values Axiom returns, such as `method`.
- `nResults` is the number of top values to return. For example, `topk(method, 10)`.

#### Example result

Without a grouping field, `topk` ranks values across the selected time range. This example shows separate ranked lists for HTTP methods, content types, and cities. Each list contains up to five values and their estimated counts.

```kusto
['sample-http-logs']
| summarize topk(method, 5), topk(content_type, 5), topk(['geo.city'], 5)
```
