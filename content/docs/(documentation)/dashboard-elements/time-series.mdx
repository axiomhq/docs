Time series charts show the change in your data over time which can help identify infrastructure issues, spikes, or dips in the data. This can be a simple line chart, an area chart, or a bar chart. A time series chart might be used to show the change in the volume of log events, error rates, latency, or other time-sensitive data.

## Thresholds

Add a threshold line to compare your data with a target value, such as a latency objective or an error limit. The chart displays the threshold as a dashed horizontal line. Line, area, and bar charts support threshold lines. Each chart displays one threshold line.

To add a threshold line:

1. In the chart editor, open **Thresholds**.
1. If the query has more than one aggregation, select the aggregation that the threshold applies to.
1. In **Value**, enter the threshold in the units of the chart's values.
1. Optional: Select a color for the line. The default color is red.
1. Optional: In **Highlight**, select **Above** or **Below** to shade the time intervals where the data crosses the threshold.

Configure the threshold with the following options:

- **Value**: The position of the line on the y-axis. Axiom extends the y-axis to show the line, even when your data doesn't reach the threshold.
- **Color**: The color of the line and of the highlighted time intervals.
- **Highlight**: Shade each time interval where a series is above or below the threshold. Series from a time comparison don't count. In stacked charts, Axiom compares the stack total with the threshold, not the individual series.

<Note>
Thresholds on dashboard charts are visual only. They don't send notifications. To get notified when a value crosses a threshold, create a [threshold monitor](/monitor-data/threshold-monitors).
</Note>
