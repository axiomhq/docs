Statistics dashboard elements display a summary of the selected metrics over a given time period. For example, you can use a statistic dashboard element to show the average, sum, min, max, and count of response times or error counts.

## Example with Builder

Select `sample-http-logs` and add the `avg(req_duration_ms)` aggregation. In the chart settings, enable **Line chart** to show how the average request duration changes over time.

## Example with APL

Use `bin_auto(_time)` to return values over time for the line chart.

```kusto
['sample-http-logs']
| summarize avg(req_duration_ms) by bin_auto(_time)
```

## Settings

Use the settings panel on the right to configure the statistic element:

- **Chart > Line chart**: Display a sparkline showing values over time alongside the summary value.
- **Value > Custom units**: Display a unit after a plain number (for example, `4.7` with `%` shows `4.7%`), or replace a unit parsed from a text value (for example, `5GB` with `GiB` shows `5GiB`). If the value already shows its own unit (a duration, or a value whose field unit is bytes, percent, or currency), custom units don't apply and Axiom keeps the saved setting. To use your own unit, convert the value to a plain number in the query first (for example, `duration / 1ms`), then set **Custom units**.
- **Value > Decimal places**: Set the number of decimal places to display.
- **Theme > Theme** and **Background**: Choose the color theme and background style.
- **Y-axis > Scale** and **Zero**: Set the vertical axis scale for the line chart and whether to include zero.
