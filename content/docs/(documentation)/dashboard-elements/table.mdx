The table dashboard element displays a summary of any attributes from your metrics, logs, or traces in a sortable table format. Each row in the table could represent a different service, host, or other entity, with columns showing various attributes or metrics for that entity.

<Prerequisites />

<CreateElement elementName="table" elementButtonLabel="Table"/>

## Example with Builder

Select `sample-http-logs`, add the `count` and `avg(req_duration_ms)` aggregations, and group by `method`. Each row shows the request count and average duration for one HTTP method.

## Example with APL

```kusto
['sample-http-logs']
| summarize count(), avg(req_duration_ms) by method
```
