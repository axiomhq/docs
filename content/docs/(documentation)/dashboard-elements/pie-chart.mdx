Pie charts can illustrate the distribution of different types of event data. Each slice represents the proportion of a specific value relative to the total. For example, a pie chart shows the proportion of HTTP requests that use each method, such as GET or POST.

<Prerequisites />

<CreateElement elementName="pie chart" elementButtonLabel="Pie"/>

## Example with Builder

Select `sample-http-logs`, add the `count` aggregation, and group by `method`. Each slice shows the request count for one HTTP method.

## Example with APL

```kusto
['sample-http-logs']
| summarize count() by method
```
