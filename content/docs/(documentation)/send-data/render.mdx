Render is a unified cloud to build and run all your apps and websites. Axiom provides complete visibility into your Render projects, allowing you to monitor the behavior of your websites and apps.

Render log streams forward logs to a syslog destination over TLS. To send them to Axiom, run a syslog receiver such as Vector on infrastructure you control, and let it forward the logs to Axiom over HTTPS.

<Prerequisites />
- [Create an account on Render](https://dashboard.render.com/login).

## Setup

### Run a syslog receiver

Set up Vector with a TLS-enabled `syslog` source and an `axiom` sink. For the configuration, see [Send data from syslog to Axiom over a secure connection](/send-data/secure-syslog). The receiver must be reachable from the internet so that Render can connect to it.

### Create log stream in Render

In Render, create a log stream. For more information, see the [Render documentation](https://render.com/docs/log-streams). As the log endpoint, use the host and port where your receiver listens, for example `syslog.example.com:6514`.

Back in your Axiom dataset, you see logs coming from Render.
