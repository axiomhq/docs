This page explains how to send syslog data to Axiom over a TLS-encrypted connection. Run a syslog receiver on infrastructure you control, point your syslog clients at it, and let the receiver forward the data to Axiom over HTTPS.

Axiom recommends [Vector](https://vector.dev/) as the receiver. Vector accepts syslog over TLS and adds the batching, retries, and error reporting that the syslog protocol lacks. If your clients are on a trusted network and don’t need TLS, you can also use the [Axiom Syslog Proxy](/send-data/syslog-proxy).

<Prerequisites />
- [Install Vector](https://vector.dev/docs/setup/installation/) on a host that your syslog clients can reach.
- A TLS certificate and private key for that host.

## Configure Vector

Create a configuration file, for example `vector.toml`, with a `syslog` source that listens over TLS and an `axiom` sink:

```toml
[sources.syslog_tls]
type = "syslog"
address = "0.0.0.0:6514"
mode = "tcp"
max_length = 102_400

[sources.syslog_tls.tls]
enabled = true
crt_file = "/etc/vector/server.crt"
key_file = "/etc/vector/server.key"

[sinks.axiom]
type = "axiom"
inputs = ["syslog_tls"]
dataset = "DATASET_NAME"
token = "API_TOKEN"
region = "AXIOM_DOMAIN"
```

Start Vector with the configuration file: `vector --config /path/to/vector.toml`.

For more configuration options, see the [Vector syslog source](https://vector.dev/docs/reference/configuration/sources/syslog/) and [Axiom sink](https://vector.dev/docs/reference/configuration/sinks/axiom/) documentation, and [Send data from Vector to Axiom](/send-data/vector).

## Configure syslog client

Configure your syslog client to send messages over TCP with TLS to the address and port where Vector listens, for example `syslog.example.com:6514`. Ensure the client trusts the certificate authority that issued the receiver’s certificate.

In Axiom, click the **Stream** tab, select your dataset, and check that the messages arrive.
