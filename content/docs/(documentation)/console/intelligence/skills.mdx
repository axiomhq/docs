Axiom Skills are instruction files that give AI coding agents specialized capabilities. Unlike [Axiom MCP Server](/console/intelligence/mcp-server), which provides a standardized protocol for tool discovery and execution, Axiom Skills work by embedding methodology and context directly into the agent's prompt.

For guidance on when to use Axiom Skills and Axiom MCP Server, see [AI agents](/console/intelligence/ai-agents-overview).

<Info>
Axiom Skills are open-source and welcome your contributions. For more information, see the [GitHub repository](https://github.com/axiomhq/skills).
</Info>

In `axiomhq/skills`, each skill lives in a directory prefixed with `axiom-`: `axiom-alerting`, `axiom-build-dashboard`, `axiom-control-costs`, `axiom-create-org`, `axiom-ingest`, `axiom-metrics-chart`, `axiom-spl-to-apl`, and `axiom-sre`.

## Available skills

Axiom provides the following skills:

<CardGroup cols={2}>
  <Card title="Axiom alerting" icon="bell" href="/console/intelligence/skills/axiom-alerting">
    Create and manage monitors and notifiers using the Axiom API
  </Card>
  <Card title="Build dashboards" icon="chart-mixed" href="/console/intelligence/skills/build-dashboards">
    Design and build Axiom dashboards via API with chart types, APL patterns, and layouts
  </Card>
  <Card title="Control costs" icon="coins" href="/console/intelligence/skills/control-costs">
    Analyze query patterns, find unused data, and build cost optimization dashboards
  </Card>
  <Card title="Create organization (axiom-create-org)" icon="plus" href="https://github.com/axiomhq/skills/tree/main/skills/axiom-create-org">
    Provision a temporary Axiom organization, store its one-time token securely, and return the claim URL
  </Card>
  <Card title="Ingest data (axiom-ingest)" icon="upload" href="https://github.com/axiomhq/skills/tree/main/skills/axiom-ingest">
    Create a dataset, ingest JSON, NDJSON, or CSV data, and confirm with a query
  </Card>
  <Card title="Metrics chart (axiom-metrics-chart)" icon="chart-line" href="https://github.com/axiomhq/skills/tree/main/skills/axiom-metrics-chart">
    Render saved Axiom metrics v2 or v3 JSON responses as multi-series line charts in Unicode, ASCII, PNG, SVG, or sixel
  </Card>
  <Card title="System Reliability Engineering (SRE)" icon="magnifying-glass-chart" href="/console/intelligence/skills/sre">
    Expert SRE investigator for incidents and debugging with hypothesis-driven methodology
  </Card>
  <Card title="Translate SPL to APL" icon="language" href="/console/intelligence/skills/translate-spl-to-apl">
    Translate Splunk SPL queries to Axiom APL for migrations
  </Card>
</CardGroup>

The `axiom-create-org` skill uses [agent-created organizations](/console/intelligence/agent-created-orgs), and `axiom-ingest` invokes it automatically when no organization is configured.
