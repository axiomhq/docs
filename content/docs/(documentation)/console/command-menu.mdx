Use the Command Menu to jump to resources, look up traces, and run actions from the keyboard anywhere in Console.

## Open the Command Menu

Press `Cmd+K` on macOS or `Ctrl+K` on Windows and Linux.

<Note>
When the cursor is inside the APL query editor, `Cmd+K` and `Ctrl+K` open [natural-language query generation](/query-data/query-editor#generate-query-using-natural-language) instead. Click outside the editor before pressing the shortcut to open the Command Menu.
</Note>

## Find resources and look up traces

Start typing to filter commands and resources across your organization:

- **Datasets, dashboards, monitors, and streams**: Search by name directly, or select **Open dataset**, **Query dataset**, **Open dashboard**, **Open monitor**, or **Open stream** to browse one resource type.
- **Traces**: Paste a 32-character hexadecimal trace ID directly in the search field, or select **Look up trace** to enter a trace ID and open it in the [trace viewer](/query-data/traces).

## Run actions and open settings

- **Page actions**: Run actions for the view you are on, such as running or saving a query, editing a dashboard, or managing a monitor.
- **Settings and account**: Jump to settings pages, copy the organization ID, switch between light and dark themes, or open documentation and status links.
