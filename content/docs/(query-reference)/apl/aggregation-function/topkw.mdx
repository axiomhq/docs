`topkw` returns an estimated top `k` list of string values weighted by an integer frequency when each row represents multiple observations.

## Usage

### Syntax

```kusto
summarize topkw(expr, k, weight) [by GroupingColumn]
```

### Parameters

- **`expr`**: The string field or expression to rank.
- **`k`**: The number of top values to return (maximum `100,000`).
- **`weight`**: An integer expression representing the frequency weight for each record. Records with a weight less than or equal to `0` are skipped. Records with a `null` weight are counted once (weight `1`).
- **`GroupingColumn`** (optional): A column to group the results by.

### Returns

Returns one array column per group (named `topkw_<expr>` by default) containing up to `k` objects with the shape `{"key": string, "count": int, "error": int}`.

## Use case examples

### Top weighted HTTP methods

This example finds the most frequent HTTP method when each row carries a pre-aggregated count.

**Query**

```kusto
datatable(method: string, weight: int)["GET", 3, "POST", 1, "GET", 1, "PUT", 1]
| summarize tk = topkw(method, 5, weight)
| project top_method = tk[0].key, weighted_count = tk[0].count
```

**Output**

| top_method | weighted_count |
|------------|----------------|
| GET        | 4              |
