`take_any` returns the values of one arbitrary row for each group. Use it when you need a value or a row from each group, and it does not matter which row.

## Usage

### Syntax

```kusto
summarize take_any(expr [, expr2, ...]) [by GroupingColumn]
summarize take_any(*) [by GroupingColumn]
```

### Parameters

- **`expr`**: An expression to return a value for.
- **`*`**: Returns all columns of one row. It leaves out the `by` columns and the columns that the `by` expressions read.
- **`GroupingColumn`** (optional): A column to group the results by. If you omit it, all records form one group.

### Returns

Returns values from one row of each group. The query does not define which row. Different runs can return different rows.

- With one expression, `take_any` skips `null` and empty string values. If every row in the group has a `null` or empty value, the result is `null`. `0` and `false` count as values.
- With more than one expression, or with `*`, all values come from the same row. That row can contain `null` and empty values.
- Separate calls, such as `take_any(a), take_any(b)`, can return values from different rows.

Each output column has the name of its expression, for example `status` for `take_any(status)`. To rename a column, write `name = take_any(expr)`.

`any` is a deprecated alias of `take_any`. It prefixes each output column name with `any_`, for example `any_status`.

<Note>
The wildcard `*` is useful to return all fields from one row, but it increases query complexity and decreases performance.
</Note>

## Use case examples

### One value for each group

This example returns one status value for each service. For `checkout`, `take_any` skips the empty status and returns `500`.

**Query**

```kusto
datatable(service: string, region: string, status: string)[
  'checkout', 'eu', '',
  'checkout', 'eu', '500',
  'frontend', 'us', '200',
]
| summarize take_any(status) by service
```

**Output**

| service  | status |
|----------|--------|
| checkout | 500    |
| frontend | 200    |

### One complete row for each group

This example returns all columns of one row for each service. With `*`, all values come from the same row, and `take_any` keeps empty values.

**Query**

```kusto
datatable(service: string, region: string, status: string)[
  'checkout', 'eu', '',
  'checkout', 'eu', '500',
  'frontend', 'us', '200',
]
| summarize take_any(*) by service
```

**Output**

| service  | region | status |
|----------|--------|--------|
| checkout | eu     |        |
| frontend | us     | 200    |

Another run can return the `checkout` row with the status `500` instead.

## Other query languages

<LanguageComparisons>
<Accordion title="Splunk SPL users">

In Splunk SPL, the `first` function of `stats` returns the first value in search order. `take_any` returns an arbitrary value.

<CodeGroup>
```sql Splunk example
| stats first(status) by method
```

```kusto APL equivalent
['sample-http-logs']
| summarize take_any(status) by method
```
</CodeGroup>

</Accordion>
<Accordion title="ANSI SQL users">

In ANSI SQL, `ANY_VALUE` returns an arbitrary value for each group, as `take_any` does.

<CodeGroup>
```sql SQL example
SELECT method, ANY_VALUE(status)
FROM sample_http_logs
GROUP BY method
```

```kusto APL equivalent
['sample-http-logs']
| summarize take_any(status) by method
```
</CodeGroup>

</Accordion>
