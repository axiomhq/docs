title: take_anyif
description: 'This page explains how to use the take_anyif aggregation function in APL.'
---

`take_anyif` returns a value from an arbitrary row that matches a condition in each group.

## Usage

### Syntax

```kusto
summarize take_anyif(expr, predicate) [by GroupingColumn]
```

### Parameters

- **`expr`**: The expression to return a value for.
- **`predicate`**: A Boolean expression that selects the rows to consider.
- **`GroupingColumn`** (optional): A column to group the results by. If you omit it, all records form one group.

### Returns

Returns a value from a matching row in each group, skipping nulls and empty strings. If no rows match, or all matching values are null or empty strings, it returns `null`.

`anyif` is a deprecated alias of `take_anyif`.

## Use case examples

### One failing URI for each service

This example returns one URI with status `500` for each service. `frontend` has no matching request, so its result is `null`.

**Query**

```kusto
datatable(service: string, status: string, uri: string)[
  'checkout', '500', '/cart',
  'checkout', '200', '/pay',
  'frontend', '200', '/home',
]
| summarize failed_uri = take_anyif(uri, status == '500'), requests = count() by service
```

**Output**

| service  | failed_uri | requests |
|----------|------------|----------|
| checkout | /cart      | 2        |
| frontend |            | 1        |

## Other query languages

<LanguageComparisons>
<Accordion title="ANSI SQL users">

In ANSI SQL, you combine `ANY_VALUE` with a `CASE` expression to return an arbitrary value from matching rows.

<CodeGroup>
```sql SQL example
SELECT method, ANY_VALUE(CASE WHEN status = '500' THEN uri END)
FROM sample_http_logs
GROUP BY method
```

```kusto APL equivalent
['sample-http-logs']
| summarize take_anyif(uri, status == '500') by method
```
