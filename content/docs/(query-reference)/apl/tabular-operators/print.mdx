title: print
description: 'This page explains how to use the print data source in APL.'
---

The `print` operator outputs a single row containing one or more evaluated scalar expressions. Use `print` to test scalar functions, inspect expressions, or create a single-row table for `let` bindings and `lookup` operations.

## Usage

### Syntax

```kusto
print [ColumnName1 =] Expression1 [, [ColumnName2 =] Expression2, ...]
```

### Parameters

- **`ColumnName`** (optional): The name to assign to the output column. If omitted, APL generates a default column name (`print_0`, `print_1`, and so on).
- **`Expression`**: A scalar expression to evaluate.

### Returns

Returns a single-row table with one column per expression.

## Examples

### Evaluate scalar expressions

**Query**

```kusto
print greeting = strcat('Hello, ', 'APL'), sum_val = 20 + 22
```

**Output**

| greeting | sum_val |
| --- | --- |
| Hello, APL | 42 |

### Bind a single-row table with `let`

**Query**

```kusto
let base = print x = 20;
base
| project x = x + 10
```

**Output**

| x |
| --- |
| 30 |
