The `set` statement sets a query option for the duration of the current query. Boolean options default to `true` when you omit `=OptionValue` (for example, `set stricttypes;`). Unknown option names return a syntax error.

## Syntax

```kusto
set OptionName [= OptionValue];
```

## Supported options

| Option | Type | Description |
| --- | --- | --- |
| `stricttypes` | `bool` | Enforces strict data type matching in expressions and declarations; mismatched types return an error. |
| `big_external_data` | `bool` | Raises [`externaldata`](/apl/tabular-operators/externaldata-operator) limits from 5 MiB and 50,000 rows to 128 MiB and 10,000,000 rows. |
| `typed_aggregations` | `bool` | Returns typed aggregation results. Under query version `2026-09-25`, this behavior is fixed by the query version and setting `typed_aggregations` returns an error. |
| `join_lhs_limit` | `int` (unsigned 32-bit) | Sets the row limit for the left-hand side of a [`join`](/apl/tabular-operators/join-operator). |

## Examples

```kusto
set stricttypes;
['sample-http-logs']
| where req_duration_ms == 5
```

```kusto
set big_external_data;
externaldata (id: string, label: string) ["https://example.com/large-lookup.csv"] with (format="csv", ignoreFirstRecord=true)
```
