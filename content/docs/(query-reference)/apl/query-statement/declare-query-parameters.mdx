---
title: 'Declare query_parameters'
description: 'This page explains how to declare query parameters in APL.'
---

The `declare query_parameters` statement declares typed parameters with default values at the top of an APL query. External callers and dashboards can supply values for these parameters at query time; when omitted, APL uses the declared default.

For dashboard filter usage, see [Filters](/query-data/filters).

## Syntax

```kusto
declare query_parameters (Name1: Type1 [= Default1], Name2: Type2 [= Default2], ...);
```

### Parameters

- **`Name`**: The parameter identifier used in the query.
- **`Type`** (optional): Scalar data type such as `string`, `int`, `long`, `real`, `bool`, `datetime`, `timespan`, or `dynamic`.
- **`Default`** (optional): Constant default value used when no runtime value is supplied.

## Example

**Query**

```kusto
declare query_parameters (
    min_duration: int = 200,
    target_method: string = 'GET'
);
['sample-http-logs']
| where method == target_method and req_duration_ms >= min_duration
| summarize count() by status
```
