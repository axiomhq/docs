The `array_shift_left` function in APL shifts the elements of an array to the left by a specified number of positions. Vacated positions on the right are filled with `null` or an optional `default_value` (elements do not wrap around; to rotate elements, use [`array_rotate_left`](/apl/scalar-functions/array-functions/array-rotate-left)).

For example, `array_shift_left(dynamic([1, 2, 3, 4, 5]), 2)` returns `[3, 4, 5, null, null]`.

## Usage

### Syntax

```kusto
array_shift_left(array, shift_count [, default_value])
```

### Parameters

| Parameter       | Type    | Description                                                                        |
|-----------------|---------|------------------------------------------------------------------------------------|
| `array`         | dynamic | The array to shift.                                                                |
| `shift_count`   | int     | The number of positions to shift elements to the left.                             |
| `default_value` | scalar  | (Optional) The value used to fill vacated positions. Defaults to `null`.           |

### Returns

An array of the same length with elements shifted to the left by `shift_count` and vacated slots filled with `default_value` (or `null`).

## Use case example

Reorganize span events to analyze dependencies in a different sequence.

**Query**

```kusto
['otel-demo-traces']
| take 50
| extend shifted_events = array_shift_left(events, 1)
```
