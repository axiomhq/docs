The `array_shift_right` function in Axiom Processing Language (APL) shifts the elements of an array to the right by a specified number of positions. Vacated positions on the left are filled with `null` or an optional `default_value` (elements do not wrap around; to rotate elements, use [`array_rotate_right`](/apl/scalar-functions/array-functions/array-rotate-right)).

For example, `array_shift_right(dynamic([1, 2, 3, 4, 5]), 2, -1)` returns `[-1, -1, 1, 2, 3]`.

## Usage

### Syntax

```kusto
array_shift_right(array, shift_count [, default_value])
```

### Parameters

| Parameter       | Type    | Description                                                                        |
|-----------------|---------|------------------------------------------------------------------------------------|
| `array`         | dynamic | The input array whose elements are shifted.                                        |
| `shift_count`   | int     | The number of positions to shift elements to the right.                            |
| `default_value` | scalar  | (Optional) The value used to fill vacated positions. Defaults to `null`.           |

### Returns

An array of the same length with elements shifted to the right by `shift_count` and vacated slots filled with `default_value` (or `null`).

## Use case example

Reorganize span events in telemetry data for visualization or debugging.

**Query**

```kusto
['otel-demo-traces']
| take 50
| extend shifted_events = array_shift_right(events, 1)
```

[Run in Playground](https://play.axiom.co/axiom-play-qf1k/query?initForm=%7B%22apl%22%3A%22%5B'otel-demo-traces'%5D%20%7C%20take%2050%20%7C%20extend%20shifted_events%20%3D%20array_shift_right(events%2C%201)%22%7D)

**Output**

```json events

```

```json shifted_events

```

The query shifts span events one position to the right and fills the first position with `null`.

## List of related functions

- [array_rotate_right](/apl/scalar-functions/array-functions/array-rotate-right): Rotates array elements to the right by a specified number of positions.
- [array_rotate_left](/apl/scalar-functions/array-functions/array-rotate-left): Rotates elements of an array to the left.
- [array_shift_left](/apl/scalar-functions/array-functions/array-shift-left): Shifts array elements to the left, filling vacated positions with `null` or a default value.

## Other query languages

<LanguageComparisons>
<Accordion title="Splunk SPL users">

In Splunk SPL, there is no direct equivalent to `array_shift_right`. APL provides `array_shift_right` natively.

<CodeGroup>
```sql Splunk example
| eval shifted_array=mvappend(null(), mvindex(array, 0, len(array)-2))
```

```kusto APL equivalent
['dataset.name']
| extend shifted_array = array_shift_right(array, 1)
```
</CodeGroup>

</Accordion>
<Accordion title="ANSI SQL users">

ANSI SQL doesn’t have a built-in function for shifting arrays. In SQL, achieving this would involve user-defined functions or complex subqueries. In APL, `array_shift_right` simplifies this operation significantly.

<CodeGroup>
```sql SQL example
-- Pseudo code in SQL
SELECT ARRAY_SHIFT_RIGHT(array_column, 1)
```

```kusto APL equivalent
['dataset.name']
| extend shifted_array = array_shift_right(array, 1)
```
</CodeGroup>

</Accordion>
